Research project

Rarefully

A phenotype-based retrieval system for rare diseases. Given a patient's symptoms as HPO terms, Rarefully ranks likely diagnoses by combining ontology-based, set-based, transformer and LLM similarity methods. It was evaluated on ten benchmark datasets and compared with established tools such as PhenoBrain, LIRICAL and Phenomizer.

  • Python
  • PyTorch / Hugging Face
  • SapBERT
  • Mistral-7B
  • FastAPI
  • Vue 3
  • HPO · ORDO · MONDO
